🐧 Conecta Aí

📚 Sobre o projeto

O Conecta Aí é um projeto educativo desenvolvido como parte de uma atividade da Alura. Seu objetivo é apresentar curiosidades sobre os pinguins de uma forma divertida e interativa, incentivando a descoberta e o aprendizado.

🎯 Objetivo

Criar uma página web simples, bonita e interativa, na qual os usuários possam descobrir informações interessantes sobre os pinguins por meio de cartões interativos.

✨ Funcionalidades

- Cartões interativos com curiosidades sobre pinguins.
- Animação de rotação dos cartões para revelar informações.
- Design organizado e intuitivo.
- Layout responsivo para diferentes tamanhos de tela.
- Conteúdo em português.

🛠️ Tecnologias utilizadas

- HTML5: estruturação do conteúdo da página.
- CSS3: estilização, layout, responsividade e animações.

📂 Estrutura do projeto

- "index.html" — contém a estrutura e o conteúdo principal da página.
- "styles.css" — contém os estilos visuais e as animações dos cartões.

🚀 Como executar o projeto

1. Acesse o repositório do projeto no GitHub.
2. Baixe os arquivos ou clone o repositório.
3. Abra o arquivo "index.html" em um navegador de internet.
4. Passe o mouse sobre os cartões ou navegue por eles com o teclado para descobrir as curiosidades.

👩‍💻 Desenvolvido para

Atividade educacional da Alura, com o objetivo de praticar conceitos de desenvolvimento web utilizando HTML e CSS.
